# 📋 Unified Management Project Dashboard

The **Unified Management Project Dashboard** is a clean and efficient task and project management system built to help individuals and teams organize their workflow. Designed as part of an academic project, it functions like a smart to-do list with a focus on productivity, clarity, and ease of use.

---

## 🚀 Features

- ✅ Create, edit, and delete tasks
- 📁 Organize tasks under specific projects
- 📊 Track project-wise progress
- ⏰ Mark tasks as completed or pending
- 💡 Simple and intuitive user interface

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript  
- **Backend**: Python (Flask)
- **Database**:JSON file storage
- **Version Control**: Git, GitHub
